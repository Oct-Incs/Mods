# JP_Beasts - 作業前に必ず読むこと

このファイルより先に `HANDOFF.md`(このMODの開発引き継ぎ資料。方針・過去の不具合と
解決策・現在の設計判断の根拠がまとまっている)を読むこと。

## 絶対厳守: Textures/ 配下のファイルには触れない(恒久的なルール)

**`Textures/` 配下のいかなる画像ファイル(PNG)も、ユーザーが今回の会話の中で
明示的に「この画像を差し替えて」「このテクスチャを変更して」と指示しない限り、
一切作成・変更・削除・上書き・リサイズ・再生成してはならない。** これは特定の
1セッション限りの注意ではなく、**新しいセッションが始まっても永久に適用される
ルール**である。

- ユーザーは自分自身でこのMODの画像を継続的に描き直しており、GitHubの`main`
  ブランチに対して直接アップロードする運用を確立している(2026-09-21〜)。
  Claude側がテクスチャに触れると、ユーザー自身の差し替え作業と衝突し、
  せっかくの新しい絵が失われる。
- **「バランス調整」「drawSizeの変更」等、画像の“表示サイズ”をXML側の数値
  (`drawSize`等)で変える作業は引き続き対応してよい。** 触ってはいけないのは
  画像ファイル自体(PNGのバイト列・ピクセル内容)であり、数値パラメータでは
  ない。今回のJorogumoのdrawSize調整(HANDOFF.md参照)がその一例。
- MOD一式をZIP等で出力する際も、`Textures/`はリポジトリに実際に入っている
  ファイルをそのまま使うこと(独自に生成・加工・プレースホルダー差し替え等を
  行わない)。
- 作業を始める前に必ず `git fetch` / `git pull` して、ユーザーが直接`main`に
  プッシュした最新のテクスチャ変更を取り込むこと。取り込まずに作業すると、
  次に出力するZIPが古い画像のままになり、ユーザーの差し替え作業を無に
  帰してしまう。

詳しい経緯は `HANDOFF.md` の該当セクションを参照。
